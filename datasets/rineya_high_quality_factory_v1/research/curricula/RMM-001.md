# RMM-001 — Modular experts, continual learning and meta-learning

Bundle priority P1; factory priority P1. Proposed initial target: 12 parents.

Learning objectives: Select an operation-appropriate competent skill from explicit qualifications. Abstain when no supplied skill supports the rule. Track old and new skill requirements without role mixing.

Semantic mechanisms: operation_specific_selection, competence_mask, abstention, skill_sequence_replay, few_shot_rule_induction, role_separation.

Oracle: Finite competence registry and explicit routing/cost constraints; rule induction accepted only when support uniquely identifies query behavior.

Specialized rubric:

- Are competence statements visible evidence rather than claimed empirical model performance?
- Does routing match the requested operation, not just domain tokens?
- Can no expert solve the task, and is abstention the correct answer then?
- Is claimed few-shot rule induction identifiable from support examples?
- Are retention records synthetic task obligations rather than measured model retention?

Curriculum:

- Level 1: Select one visibly qualified skill for one operation.
- Level 2: Rename skill IDs and reorder registry entries.
- Level 3: Combine competence, cost and applicability constraints.
- Level 4: Route a sequence while preserving prior obligations.
- Level 5: Compose predictor/proposer/critic procedures with distinct roles.
- Level 6: Conflicting qualifications, attractive incompetent expert and unsupported-rule traps.
- Level 7: Held-out qualification patterns, task mixtures and rule families.

Measure complexity with: expert_count, operation_count, constraint_count, sequence_length, support_examples.

Expand by: Provide synthetic routing and support/query episodes first; defer learning-curve or retention claims to separate model studies.

Scope limitation: True forgetting, learned router drift and adaptation efficacy cannot be measured by dataset construction.
