# RBM-001 — Belief-state models and metacognitive control

Bundle priority P1; factory priority P1. Proposed initial target: 12 parents.

Learning objectives: Update a belief set from permitted observations. Distinguish known, unknown and conflicting information. Choose inspection/abstention when it has explicit expected utility.

Semantic mechanisms: partial_observation, set_belief_update, bayesian_update, information_action, contradictory_evidence, observation_delay.

Oracle: Enumerate finite hidden states using exact rational probabilities where stated; independent observation-consistency filter and explicit observation-cost model.

Specialized rubric:

- Is latent truth excluded from the student-visible lane?
- Are likelihood/prior assumptions stated when a numeric posterior is required?
- Does ambiguity remain when observations are insufficient?
- Are inspection value and cost defined, including tie/abstain behavior?
- Are contradictory signals governed by a noise/authority rule?

Curriculum:

- Level 1: Identify one unknown field from an incomplete observation.
- Level 2: Equivalent observation encodings and renamed hidden states.
- Level 3: Update multiple constraints or one explicit noisy observation.
- Level 4: Accumulate evidence over several observation/action steps.
- Level 5: Combine memory retrieval, belief update and information gathering.
- Level 6: Confident shared-shortcut and misleading-observation traps.
- Level 7: Held-out noise/delay regimes and hidden-state structures.

Measure complexity with: hidden_state_count, observation_count, belief_support_size, history_length, inspection_cost.

Expand by: Begin finite deterministic belief sets; add rational Bayes only after enumeration parity, then utility of inspect versus answer.

Scope limitation: Calibration and learned introspective confidence require model predictions; oracle beliefs are a privileged ceiling.

Reuse: Reuse existing abstention/uncertainty work cautiously. The failed prerequisite deferral is a required negative case. Connect later to adaptive-depth work only after finite-compute benefit is measured.
