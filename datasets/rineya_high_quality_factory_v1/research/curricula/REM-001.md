# REM-001 — Episodic, associative and procedural memory

Bundle priority P1; factory priority P1. Proposed initial target: 12 parents.

Learning objectives: Retrieve decisive evidence with event time and provenance. Apply correction/supersession without stale-fact errors. Ignore irrelevant memory and abstain on unresolved conflict.

Semantic mechanisms: relevant_retrieval, timestamp_update, supersession, source_authority, unresolved_conflict, delayed_dependency, procedure_memory.

Oracle: Timestamped event ledger with explicit authority/supersession policy; independent query resolver outputs evidence IDs and answer/unknown.

Specialized rubric:

- Does the correct answer require retrieval rather than being repeated in the query?
- Are event time and statement time distinguished?
- Is source authority or supersession policy explicit for conflicts?
- Are supporting facts available before the query, with no future evidence?
- Can the reader identify evidence and uncertainty without memorizing names?

Curriculum:

- Level 1: Retrieve one visible historical fact.
- Level 2: Rename entities and paraphrase queries with equal evidence.
- Level 3: Resolve one explicit update or authority-conditioned conflict.
- Level 4: Combine separated records and delayed dependencies.
- Level 5: Retrieve a stored procedure and execute it using current corrected facts.
- Level 6: Stale summaries, recent distractors and unsupported confidence traps.
- Level 7: Held-out update patterns, longer histories and changed procedure combinations.

Measure complexity with: history_length, relevant_record_count, distractor_count, update_depth, time_gap.

Expand by: Increase genuine corrections and unresolved conflicts; vary chronology independently of answer labels and keep provenance in evidence targets.

Scope limitation: Storage compression, learned write policies and dense fact consolidation are model/system hypotheses, not demonstrated memory gains.

Reuse: Prior history identifies RHF-001 on research/rineya-hebbian-fact-memory-v1 and factorized/triadic memory branches. These overlaps were not fully re-audited here; verify and reuse before coding. Do not label prior synthetic memory results as native gains.
