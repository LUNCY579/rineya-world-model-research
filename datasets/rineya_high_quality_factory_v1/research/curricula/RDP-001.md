# RDP-001 — Diffusion and revisable proposal models

Bundle priority P2; factory priority P2. Proposed initial target: 12 parents.

Learning objectives: Identify and repair bounded candidate errors. Preserve valid candidate prefixes and avoid introducing new violations. Distinguish semantic solution diversity from surface variation.

Semantic mechanisms: first_fault_repair, bounded_edit, prefix_preservation, iterative_revision, multi_candidate_selection, repair_tie.

Oracle: Replay candidate against independent simulator; bounded edit enumeration/BFS defines repair feasibility and minimality only within declared cost/bound.

Specialized rubric:

- Does the original candidate actually contain the alleged defect?
- Is each corrected plan executable and goal-reaching?
- Is minimality proved within a visible edit metric/bound?
- Are alternative equally good repairs accepted?
- Does an extra revision create a regression or only reword the same plan?

Curriculum:

- Level 1: Repair one corrupted arithmetic/transition step.
- Level 2: Repair renamed equivalent candidates.
- Level 3: Repair a failed precondition with explicit constraints.
- Level 4: Repair the earliest failure and dependent suffix of a plan.
- Level 5: Repair plans composed of several reusable procedures.
- Level 6: Tempting local fix that breaks later constraints.
- Level 7: Held-out fault combinations, horizons and graph motifs.

Measure complexity with: edit_distance, fault_count, suffix_dependency_depth, candidate_count, plan_length.

Expand by: Add shared-start-candidate repair comparisons, ties and unrepairable-within-bound labels before masked revision tasks.

Scope limitation: A verified revision dataset is not a diffusion model; denoising speed, diversity and learning benefit remain unmeasured.

Reuse: Coordinate with existing repeated-sampling/inference-compute experiments before making another proposer harness. No new model downloads or paid APIs are required by this bundle.

Linked proposed experiments: E25, E26, E27. Resource anchors: P18, P19, P32.
