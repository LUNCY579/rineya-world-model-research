# RCWM-001 roadmap

Use `experiment_registry.csv` as the machine-readable queue. All native work is gated, not scheduled.
The route is G0 contracts -> G1 scalar/measured instrument -> G2 learned continuous consequences ->
G3 goal transfer and clustering -> G4 long-horizon/parallel composition -> G5 native typed slots ->
G6 optional distillation/imagined RL. Compute-depth and visual extensions depend on prior qualification.

## Next three concrete deliverables

1. Reconcile current source identity and capture status; fill G0 manifest and admission limits.
2. Implement a real grouped-parent simulator suite and the matched scalar evaluator, preserving the
   same candidate sets as the consequence evaluator.
3. Preregister B2/B3/B4 endpoint, resource budget, label budget and sealed evaluation rules before a
   native learned-consequence campaign.

Do not start by adding codebooks, recurrence, a new vision encoder and policy RL in the same change.
A failed baseline can reveal a useful simpler answer. Archive gates and explicit decisions. Keep work
manual unless a later user instruction separately authorizes a specific execution workflow.
