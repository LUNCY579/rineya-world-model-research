# Third-party notices and resource policy

The cited papers, author project pages, benchmarks and documentation belong to their respective
creators. They are linked and discussed in original annotations; full papers, datasets, pretrained
Rineya weights and third-party source repositories are not redistributed in this ZIP. A reference
link is not a license grant. Check the exact code/data license and pinned revision before reuse.

The reference Python code and tiny synthetic checkpoint were created for this bundle. PyTorch,
NumPy, pytest, JSON Schema tooling, Pandoc and LaTeX were used as installed tools, not bundled as
third-party source packages. The PDF uses installed fonts; no font files are distributed.

The bundle is a research starting point, not a production assurance, security certification or warranty
of model quality. Checkpoint files should only be loaded from trusted sources with safe loading options.
